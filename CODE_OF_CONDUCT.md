# Code of Conduct

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, give constructive technical feedback, and keep discussion on the work. Harassment of any kind is not accepted.

Report unacceptable behaviour to the team lead, Dharshini R, through the contact address on the team's GitHub profile. All reports are handled in confidence.
